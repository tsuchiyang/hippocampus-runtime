Hippocampus Runtime（海马体） is the public project name, formerly Codex Memory
Runtime. The distribution `codex-memory-runtime`, import `codex_memory` and
command `codex-memory-hook` are unchanged. Existing copyright attribution is
retained rather than rewritten by this branding change.

The project software is offered under the MIT license in LICENSE. Copyright is
attributed to the Codex Memory Runtime contributors; no trademark ownership or

This public Alpha is a history-free software export. Private development records,
host authentication, real Hook registrations and machine-bound historical
acceptance tooling are not redistributed. See docs/PROVENANCE.md and TESTING.md.

Runtime uses the Python standard library, including sqlite3. No Python interpreter,
SQLite DLL, model weights, Torch, FlagEmbedding, OpenAI client, Codex binary or
third-party runtime package is bundled. Those separately installed products retain
their own licenses. Hatchling, uv, pytest and pytest-cov are development/build
tools, not relicensed by this project's LICENSE.

Names such as Codex, OpenAI, SQLite and BGE-M3 identify interoperability targets;
their mention is not an endorsement or an included distribution license.
The MIT text follows the SPDX MIT standard license. Tool-assisted source review
did not establish legal title; the repository owner must confirm the proposed
